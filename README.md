# inventory_manager
A Python command-line application for managing product inventory. Built as a personal project while learning Python and preparing for a Home Depot IT internship.

## Features
- Add products with name, quantity, and price
- View full inventory list
- Remove products by name
- Saves inventory to a CSV file so data persists between sessions

## How to Run
1. Make sure Python is installed
2. Download the project
3. Run this command: py inventory.py

## Why I Built This
I work at Home Depot and understand how important inventory management is to retail operations. I built this project to practice Python while solving a real problem I see every day at work.
